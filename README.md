# 非均匀采样浮动均值谱估计 / Floating-mean periodogram

面向非均匀采样天文时间序列的可复用周期图模块：在每个候选频率上拟合
`y = c + a·cos(2πft) + b·sin(2πft)`（常数均值**浮动**，而非先扣除均值），
采用加权 Householder QR 最小二乘；功率定义为相对常量模型的加权残差平方和
（SSE）减少比例。另计算采样窗口的归一化模用于解释周期别名。

此外提供 `joint_fit`：在**最多 12 点**的候选网格上穷举枚举**最多两个频率**
的联合模型（单频 3 列 / 双频 5 列，同一套加权 QR 线性拟合），按残差 SSE
升序、频率元组字典序选解。

**不使用 FFT、不把不等间隔观测插值/补零成均匀序列**；每个观测就是设计矩阵的
一行，重复时间、未排序时间均可直接处理。

- Python：**3.14.7**（仅用标准库 `math`、`dataclasses`、`numbers`、`collections.abc`）
- 第三方依赖：**无**；安装 Python 后即可运行
- 完全离线：无网络、账号、密钥、数据库、中间件、云 API、Docker
- 示例数据由仓库内确定性 LCG 代码生成，无外部附件

## 接口

```python
from periodogram import periodogram, PeriodogramError, PeriodogramResult

res = periodogram(times, values, weights, frequencies,
                  *, top_k=None, min_separation=0.0,
                  rank_tol=None, selection_budget=None)
```

| 参数 | 契约 |
|---|---|
| `times` | list/tuple 实数，有限（拒绝 NaN/±Inf），长度 3..200；可不排序、可重复 |
| `values` | 同长度有限实数 |
| `weights` | 同长度**严格正**有限权重；`None` 表示等权。全局权重缩放不改变结果 |
| `frequencies` | 1..300 个候选频率，**严格递增、严格为正**的有限实数（单位：周/时间单位） |
| `top_k` | 正整数且 ≤ 候选数；`None` 表示 `min(5, 候选数)`。**拒绝 bool** |
| `min_separation` | 非负有限频率排斥距离；已选峰与候选 `|Δf| < min_separation` 时排斥，`|Δf| == min_separation` **允许**（边界内闭） |
| `rank_tol` | 数值秩阈值，`|R_jj| > rank_tol·max|R_ii|` 判为非零；默认 `n·eps`；可覆盖范围 `(0,1)` |
| `selection_budget` | top-K 选择时检查的候选数上限；`None` = 全部候选（穷举扫描） |

返回不可变值对象 `PeriodogramResult`（逐频率数组 + 峰列表）：

- `frequencies, powers, amplitudes, phases, ranks, constants, sses`：每个候选
  频率的功率、幅度 `hypot(a,b)`、相位 `atan2(b,a)∈(−π,π]`、设计矩阵数值秩、
  拟合常数 c、加权 SSE。
- `sse0`、`weighted_mean`：常量模型 SSE 与加权均值。
- `window`（复数，τ=t−times[0] 参考系）与 `window_modulus`
  `= |Σ w_k exp(i2πft_k)| / Σw_k ∈ [0,1]`；模与时间原点无关，用于别名解释。
- `local_peaks`：严格局部功率极大（`P[i-1]<P[i]>P[i+1]`，端点永不算峰）。
- `top_peaks`：按功率降序（功率并列时频率升序）贪心选取，施加显式排斥距离；
  元素为 `FrequencyPeak(index, frequency, power, amplitude, phase, rank, sse,
  window_modulus)`。
- `selection_status`：
  - `"complete"`：扫描了全部候选；若 `top_k_found < top_k_requested`，
    这是在确定性贪心规则下**可证明无更多可选峰**的结果；
  - `"budget_exhausted"`：`selection_budget` 用尽、扫描提前终止；
    对未检查候选不作任何断言。**预算耗尽与证明无解严格分开**。

### 功率定义

`P(f) = (SSE0 − SSE(f)) / SSE0`，其中 `SSE0 = min_c Σw(y−c)²`（浮动均值常量
模型），`SSE(f)` 为三参数模型的最小二乘残差。普通条件下 `0 ≤ P ≤ 1`。

## 双频联合枚举 `joint_fit`

```python
from periodogram import joint_fit, JointFitResult, FrequencyCombination

res = joint_fit(times, values, weights, frequencies, *, rank_tol=None)
```

| 参数 | 契约 |
|---|---|
| `times/values/weights` | 与 `periodogram` 完全相同（3..200 点、严格正权重或 `None`） |
| `frequencies` | **1..12** 个严格递增、严格为正的有限候选频率（`MAX_JOINT_GRID=12`） |
| `rank_tol` | 同 `periodogram`；默认 `n·eps`，覆盖范围 `(0,1)` |

对网格上每个单频 `f_i` 拟合三参数模型，并对每对 `i < j` 联合拟合

`y = c + a₁cos(2πfᵢt) + b₁sin(2πfᵢt) + a₂cos(2πfⱼt) + b₂sin(2πfⱼt)`

（5 列，同一套加权 Householder QR 与数值秩判定；无第三个频率、无连续频率
精化）。12 点网格共枚举 `12 + C(12,2) = 78` 个模型。

返回不可变值对象 `JointFitResult`：

- `frequencies`：候选网格；`sse0`、`weighted_mean`：常量模型基准（口径同单频）。
- `combinations`：**全部**枚举模型组成的元组，每个为不可变
  `FrequencyCombination(indices, frequencies, constant, amplitudes, phases,
  rank, sse, power)`；双频时 `amplitudes/phases` 为按频率顺序的二元组。
- `best = combinations[0]`。

**选解规则（确定性、可复现）**：全表按键 `(sse, frequencies)` 升序排列——
先比加权残差 SSE；SSE 严格相等时比频率元组的 Python 词典序。单频元组
`(fᵢ,)` 是任何以 `fᵢ` 开头的频率对的前缀，因此退化频率对（列空间被单频
覆盖、SSE 相同）永远不会挤掉对应单频；低频组合在精确平局中先胜出。

**秩亏设计不抛错**：别名频率对（采样格点上两频率的 cos/sin 列重合或反号）、
观测数少于 5 的频率对模型，都通过 `rank` 如实报告秩，被判定为零空间的列
系数置 0（与单频入口同一规则），而非编造数值或报错。

## 错误语义

- 所有数值输入拒绝 NaN / Infinity；整数参数（`top_k`、`selection_budget`）
  拒绝 `bool`（`True/False` 不会被当作 1/0），数组内的布尔元素同样拒绝。
  `joint_fit` 的 `rank_tol` 同为实数参数，同样拒绝 `bool`。
- 非法输入抛 `PeriodogramError`（`ValueError` 子类），消息**点名参数与元素
  下标**（如 `values[7]: NaN is not allowed`、`frequencies[2]: candidates must
  be strictly increasing`、`frequencies: joint_fit enumerates at most 12
  candidates, got 13`），不静默纠正、不截断、不重排用户数据。
- 全部输入校验先于任何计算；两个入口均为纯函数（不写文件、不修改入参、
  不缓存全局状态），不存在“部分完成”状态——非法调用后同一批对象再次调用
  结果不受影响。
- 权重必须严格为正（零/负权重直接拒绝，而不是悄悄丢点）。
- **秩亏不是非法输入**：`joint_fit` 遇到列重合的别名对或 `n < 5` 的双频模型
  时照常返回，秩与零方向系数按文档约定报告。

## 设计取舍

1. **加权 Householder QR（逐行构造 W^½A，3 列）**：不组正规方程，避免条件数
   平方化；n≤200、m≤300 下纯 Python 约 0.1 秒。这是本题核心算法，不调用任何
   第三方谱分析实现。
2. **时间原点重定中心**：内部以 `τ = t − times[0]` 拟合（大原点下保证三角
   参数有界），再用闭式旋转把 (a,b) 转回原时间参考系。功率、幅度、窗口模对
   原点平移在数学上严格不变；`window` 的复相位以 τ 参考系报告。
3. **SSE 直接按拟合模型残差计算**：当某列被数值秩判定跳过（秩亏）时，
   `Qᵀb` 的残差能量仍分布在被跳过列方向，直接取尾部会漏算；用投影拟合值
   计算对任意秩都无歧义。
4. **逐位常量值约定**：当所有 `values` 位级相等时，精确返回 `SSE0=0`、
   每频率 `P=0`、`a=b=0`、`c=该常量`，避免 0/0（这是文档化约定，不是用容差
   掩盖）。非位级常量的近常量数据照常按浮点计算。
5. **无插值/无网格/无 FFT**：候选频率由调用方显式给出；模块不假设均匀采样，
   也不做任何零填充。
6. **采样窗口**：报告 `|W|/Σw` 而非原始复和，天然归一到 `[0,1]` 且对权重
   全局缩放不变；均匀采样在 `f_s=1/Δt` 处模为 1，直接指示别名间隔。
7. **双频枚举复用同一 QR 内核**：`joint_fit` 对 3 列与 5 列设计调用同一个
   加权 Householder QR 与秩判定函数，三角列在网格上只算一次后复用；最多
   78 次拟合、纯 Python 约 0.005 秒。选解是**全枚举**而非贪心逐峰——
   两个频率同时进入设计矩阵，正确处理了单频扫描无法表达的频率间竞争；
   枚举上限即接口边界（12 点），不做更大规模的组合优化。

## 已知限制（本题数学子集，不宣称行业标准兼容）

- 仅实现本题契约：单变量时间、正弦+常量模型、固定候选网格、标量权重。
  `joint_fit` **最多联合两个频率**（不做三频及以上）、**不做连续频率精化**、
  不做别名模型之间的显式统计比较（退化对仅靠 `(SSE, 频率元组)` 规则
  确定性排序，不做 FAP/贝叶斯模型选择）；也不做误差棒传播、显著性/FAP
  统计检验、Lomb–Scargle 标准时移或任何行业标准合规声明。
- `joint_fit` 候选网格上限 12（穷举 `m + m(m−1)/2 ≤ 78` 个模型）；
  这是接口边界而非性能目标，不支持更大网格。
- 不做频率精化（抛物线/亚格点拟合）；峰位置精度受候选网格步长限制，
  离线格点的信号会有频谱泄漏（幅度被低估），这是物理效应而非数值缺陷。
  近频双信号只有在时间跨度覆盖至少约一个拍频周期时才可分辨；
  更接近的频率会在 5 列设计上产生高条件数，此时系数精度由输入数据
  （噪声、时长）决定，秩容差可显式收紧/放宽但模块不发明可分辨性。
- `phases` 在幅度接近 0 的 bin（以及 `joint_fit` 中被秩判定置零的
  零空间方向）上无物理意义（atan2(0,0)=0 的延续）。
- 观测时间跨度与周期相比极大时，二进制64浮点本身的时间量化会改变输入问题
   （例如原点平移 1e9 后相对时间误差可达 ~2·ulp(1e9)≈2.4e-7）；模块在
  “给定的浮点输入”上精确求解，但不消除输入表示误差。
- 纯解释器实现，规模上限即接口边界（单频 200×300；双频网格 12 点）；
  不追求更大规模性能。

## 误差口径（README 明确承诺，不用宽容差掩盖边界）

二进制64 浮点，机器精度 `eps = 2.220446049250313e-16`。测试中的独立参考
（等间隔 DFT 闭式和、3×3 手工加权正规方程高斯消元、窗口直接几何求和）
**不调用被测核心**产生期望值；与被测代码的往返一致仅作补充检查。

- **等间隔、信号落在 DFT 格点**：残差 SSE `< 1e-24`（相对功率 ≈ 1，
  达 `places=10`），幅度/相位/常数与解析 DFT 系数一致到 `places=10..12`。
- **非均匀时间 + 任意正权重**：QR 与独立正规方程参考逐 bin 比较
  `SSE/SSE0`，容差 `1e-18 + 1e-12·量值`（即 ~12 位有效数字）；
  幅度、相位、常数 `places=10`。在最病态 bin（拟合系数 ~50）正规方程自身
  条件数平方化、约有 1e-10 绝对误差，测试显式以
  `1e-11 + 1e-10·max(1,|x|)` 为界并要求 QR 不劣于参考——该容差是正规方程
  的已知误差界，非掩盖边界错误的“大网”。
- **大原点平移（1e9）**：两帧各自对照独立参考（参考也在小角度 τ 帧求解）；
  跨帧相位旋转律 `φ₂−φ₁ = 2πfT` 以 `places=5` 检验——该比较中的旋转角
  高达 ~2.4e9 rad，`places=5` 对应约 2e-15 的**相对**精度。输入时间量化
  （≤2·ulp(T)，测试中先实测上界）作为真实输入扰动单独说明。
- **窗口模**：与直接复数几何求和一致到 `places=12..13`，且 ≤ 1+1e-15。
- **别名/秩亏/重复时间**：镜像别名两 bin 功率差 `places=12`；秩亏采样
  功率精确为 0、秩 ≤2；重复时间与独立正规方程一致到 `places=10`。
- **双频枚举（`joint_fit`）**：独立参考为手建的加权 5×5 正规方程
  （部分主元高斯消元，与 QR 完全不同算法，不调用被测核心）。
  - 等间隔、两个 DFT 格点纯音：频率对 SSE `< 1e-24`、功率达 `places=10`，
    幅度/相位/常数与闭式 DFT 系数一致到 `places=11`；并手算核对
    “单频拟合恰留下另一正交音能量 `nA²/2`”。
  - 非均匀时间 + 任意正权重（5 点网格 = 5 单频 + 10 频率对 = 15 个模型）：
    逐模型与正规方程参考比较 SSE（`1e-17 + 1e-11·量值`）与 τ 帧系数
    （`1e-10 + 1e-9·量值`，正规方程平方条件数的已知误差界）。
  - 近频压力例（Δf=0.03、跨度仅略大于一个拍频周期）实测 QR 与参考
    SSE 相对差 ~3e-15、系数差 ~1e-16，测试以 `places=9` /
    `1e-17+1e-12·量值` 为界。
  - 退化设计：别名频率对秩精确为 3 且 SSE 与单频相等（`places=12`）；
    `n=4 < 5` 时所有模型秩 ≤4 且有限；位级常量数据每模型 SSE 精确为 0，
    并据此确定性验证 `(SSE, 频率元组)` 字典序/前缀平局规则。

## 测试与 demo 内容

`tests/test_periodogram.py`（43 个用例 = 原 25 个 + 新增 18 个）覆盖：

- 等间隔 DFT 解析恢复（格点纯谐波功率=1、闭式 DFT 系数）；
- 手工加权正规方程独立参考（非均匀时间、非均匀权重、权重全局缩放不变）；
- 大时间原点平移（两帧对独立参考 + 解析相位旋转律）、重复时间、未排序时间、
  采样秩亏；
- 常量值（精确零功率约定）、周期镜像别名（`f0` 与 `f_s−f0` 等权，窗口解释）；
- 局部峰/端点规则、排斥距离边界内闭、并列确定性、预算耗尽 vs 证明无解；
- 全部单频入口输入校验（NaN/Inf、bool、长度/上限、频率递增与为正、
  类型可定位错误）；
- **`joint_fit` 正常**：双 DFT 格点纯音精确恢复（手算 `nA²/2` 单频残差）、
  单音时多个精确模型的选解、全表 15 模型对独立 5×5 正规方程、
  权重全局缩放不变、与单频入口的单频结果往返一致、入参不被修改；
- **`joint_fit` 边界**：近频 Δf=0.03 仍可分辨且对参考；别名频率对秩降为 3、
  `n=4<5` 不抛错且秩 ≤4、全部观测同时刻、位级常量数据的精确平局规则、
  12 点网格恰好枚举 78 个模型；
- **`joint_fit` 失败**：13 点网格、空网格、非递增/非正频率、NaN/Inf、
  数组内 bool、类型错误、长度/观测数边界、`rank_tol` 越界与 bool、
  非法调用后无残留状态。

`python demo.py`（固定输入、确定性，总耗时约 0.1 秒，远低于 90 秒预算）：

1. **正常结果（单频）**：25 晚 × 3 次的夜间观测节奏、注入 f=1.70/day 信号；
   真实计算出 `1.70 / 0.70 / 2.70` 三峰歧义（P≈0.999 与 0.989），
   采样窗口在 1.00/day 处 |W|/Σw≈0.995 解释周日别名；主峰再用独立
   3×3 正规方程现场核对（差异 ~1e-16）。
2. **实际触发的拒绝（单频）**：NaN 观测与 `top_k=True` 都真正抛出
   `PeriodogramError` 并打印可定位消息（不是预录文本）。
3. **正常结果（双频）**：40 个非均匀观测上注入 0.20/0.37 两个频率，
   8 点网格枚举 36 个模型，选中 `(0.20, 0.37)`（SSE≈0.005，其余模型
   SSE≥10），再用独立 5×5 正规方程现场核对（差异 ~1e-15）。
4. **边界（双频）**：Δf=0.03 近频对仍被选出（频率对/最佳单频 SSE 比
   ≈1e-4）；24 小时采样的 f=3/21 别名对秩降为 3、第二幅度报 0；
   4 观测拟合 5 列模型秩 ≤4 不报错。
5. **实际触发的拒绝（双频）**：13 点网格与重复频率网格都真正抛出
   `PeriodogramError`。
