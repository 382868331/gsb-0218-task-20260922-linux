# fmperiodogram — 非均匀采样浮动均值谱估计

纯 Python 标准库实现的“浮动均值周期图 / floating-mean periodogram”，
面向**非均匀（不等间隔）天文时间序列**。核心算法自实现，不调用任何
第三方谱分析库，也**绝不**把不等间隔观测补零或重采样成均匀序列。

## 运行环境

- Python **3.14.7**（不使用 3.14 之外的语法；3.10+ 的 `dataclasses`/`typing` 亦可运行，但以 3.14.7 验收）
- 操作系统：Linux 原生
- **零第三方依赖**：仅用标准库（`math`、`dataclasses`、`typing`）
- 完全离线：无网络、账号、密钥、数据库、中间件、云 API、Docker
- 演示/测试数据由仓库内确定性代码生成，不读取任何外部附件

## 接口

```python
from fmperiodogram import periodogram

res = periodogram(times, values, weights, frequencies,
                  *, top_k=5, min_separation=None,
                  alias_threshold=0.8)
```

### 参数

| 参数 | 契约 |
|---|---|
| `times` | list/tuple，长度 **3–200**，有限实数；可乱序、可重复，不要求等间隔 |
| `values` | 同长度，有限实数 |
| `weights` | `None`（=全等权 1）或同长度序列；每个权重必须**严格为正**有限数，零/负权重报错而非丢弃 |
| `frequencies` | 必填，长度 **1–300** 的**严格递增正频率**（`f > 0`，无重复、无乱序） |
| `top_k` | 关键字，`int`，1–300；排斥选择返回峰数的**上限**（峰不够则返回更少） |
| `min_separation` | 关键字，正实数频率排斥距离；已入选峰与之 `|Δf| <=` 此值的候选被排斥。`None` 时取候选网格平均间距 `(fmax-fmin)/(n-1)`（单频率时为 +∞） |
| `alias_threshold` | 关键字，`[0,1]` 实数；归一窗口模达到该值才报告别名链接 |

`times/values/weights/frequencies/min_separation/alias_threshold` 接受
`int` 或 `float`，但**拒绝 `bool`**（`True` 不当成 1）、拒绝 `NaN/±Infinity`，
拒绝字符串等非数值类型。

### 返回 `PeriodogramResult`（不可变 dataclass）

- `points: tuple[FrequencyPoint, ...]` — 每个候选频率一个点，按输入频率序：
  `frequency, power, amplitude, phase, sse, rank, window_modulus, local_peak`
- `peaks` — 严格局部最大功率峰（端点不计；功率平台不标峰），按频率升序
- `top` — 从局部峰中按功率降序（平局取低频）贪心、以 `min_separation`
  显式排斥选出的至多 `top_k` 个峰，按频率升序
- `aliases: tuple[AliasLink, ...]` — top 峰与其它局部峰之间的采样窗口
  别名链接（无序对去重）
- `constant, sse_constant, total_weight, phase_epoch, constant_series`
- `top_k, min_separation, alias_threshold` — 回显实际生效的参数

### 数学定义

每个候选频率 f 独立拟合加权最小二乘模型

```
v_i = c + a·cos(2π f t_i) + b·sin(2π f t_i) + e_i,    最小化 Σ w_i e_i²
```

- **功率**（浮动均值归一功率）：`P(f) = (SSE_const − SSE_full(f)) / SSE_const`，
  其中 `SSE_const = Σ w_i (v_i − c̄)²`，`c̄ = Σ w_i v_i / Σ w_i`。
  因为常量模型是三参数模型的约束子模型，必有 `0 ≤ P ≤ 1`。
- **幅度/相位**：`A = hypot(a,b)`，模型写作 `c + A·cos(2π f (t − t0) + φ)`，
  故 `φ = atan2(−b, a)`，`t0 = phase_epoch = times[0]`。
- **rank**：加权设计矩阵 QR 的对角秩估计，
  `rank = #{k : |R_kk| ≥ 1e-12 · max_j |R_jj|}`。
- **采样窗口**：`W(f) = Σ_i w_i · exp(i 2π f (t_i − t0))`，
  `window_modulus = |W(f)| / Σ w_i ∈ [0,1]`。

### 别名解释

若两个局部峰 `f1, f2` 在当前采样时刻上给出几乎相同的基向量，则不可区分。
有两种机制，分别在窗口谱的两个拍频上检验：

- **平移型**（`beat_kind="difference"`，拍频 `|f2−f1|`）：
  `e^{i2π f2 t} ≈ e^{i2π f1 t}`，例如两个采样间隔存在公倍数时的低频拍；
- **镜像型**（`beat_kind="sum"`，拍频 `f1+f2`）：
  `cos(2π f2 t) ≈ cos(2π f1 t)`。均匀采样率 `fs=1/Δt` 下的经典
  Nyquist 折叠别名 `f2 = fs − f1` 即属此类（`f1+f2 = fs`，
  `W(fs)` 各项恒为 1，归一窗口模恰为 1）。

取两种拍频中归一窗口模 `≥ alias_threshold` 且较大者报告。

## 误差口径（float64，双精度）

以下口径基于 IEEE-754 binary64，机器精度 `eps ≈ 2.22e-16`。**不以宽容差
掩盖边界错误**：容差均来自下列推导，测试中离散结论（峰位置、秩、异常）
一律精确断言。

1. **拟合求解**：加权 Householder QR（逐列正交、`math.hypot` 求列范数、
   `math.fsum` 求点积）。非退化时，测试中 SSE、幅度、相位与测试内独立的
   3×3 加权正规方程（部分主元高斯消元）参考吻合到约 `1e-9`（SSE 绝对
   误差，SSE 为 O(1) 量级）；等间隔整周期解析情形功率吻合到 `1e-11`。
2. **功率钳制**：仅把理论上属于 `[0,1]` 但落入
   `[−1e-10, 1+1e-10]` 的功率钳回端点；越界超过 `1e-10` 直接抛
   `FloatingPointError`（表示数值路径有缺陷，不掩盖）。
3. **大时间原点平移**：内部一律先减 `t0 = times[0]` 再算三角函数。
   平移 T0 后，时刻减法的绝对误差 `δt ≲ eps·T0`，引起相位角误差
   `δφ ≲ 2π f·eps·T0`（如 T0=1e9、f≈1 时 ≈1.5e-6 rad）。这是
   **float64 表示极限而非算法缺陷**；测试以推导界 `2e-6` 校验各谱量
   的平移一致性，而峰位置、峰性等离散结论要求完全一致。
4. **窗口模**：`fsum` 求和，理论上界为 1；仅当计算值超出且偏差
   `≤ 1e-12` 时钳到 1。
5. **常量序列**（`SSE_const == 0`）：功率、幅度、相位约定为精确 0
   （退化解族，不保留 QR 的 eps 级噪声）。

## 设计取舍

- **加权 QR 而非正规方程**：正规方程会把条件数平方；QR 在重复时间、
  近共线列（如候选频率极低）下更稳，且对角元直接给出秩。秩亏列系数置 0。
- **浮动均值**：每个频率都重新拟合常量 `c`，不预先减均值（加权均值
  与频率项不正交，尤其在非均匀采样下）。
- **不做 FFT / 补零 / 网格化**：非均匀点直接进入 QR，零近似地尊重
  真实采样时刻；候选频率由调用方显式给定。
- **峰选择为显式距离贪心**：`min_separation` 的语义是“已入选峰的
  `|Δf|` 小于等于该值即排斥”，可解释、可复现；不做隐式网格假设。
- **无状态、无部分变更**：全部输入校验先于任何计算；函数不修改入参，
  失败时不产生任何结果对象。
- **搜索预算与“无解”分离**：本问题是有限候选网格上的确定性枚举
  （≤300 个频率全部显式计算，不存在预算耗尽的搜索路径）。“没有局部峰”
  （常量/平坦序列）以空 `peaks/top` 元组如实返回，绝不伪造或报错。

## 已知限制 / 非目标

- 只实现本题契约的数学子集：**单频点独立三参数模型**。不做多频联合
  拟合、显著性/FAP 统计检验、噪声模型、红噪声、误差棒、Lomb-Scargle
  的经典（非加权浮动均值）归一化变体；不宣称兼容任何行业标准。
- 频率网格分辨率即候选列表本身；不做网格外插值或峰值精化（抛物插值等）。
- 重复时间戳合法：它们在加权 LS 中天然等价于权重合并的单行（有测试
  覆盖）；全部时刻相同时设计矩阵秩为 1，谱无信息，功率为 0，不报错。
- 规模上限是**接口边界**：>200 观测或 >300 频率直接
  `PeriodogramInputError`。上限规模实测约 0.14 秒（纯 Python）。
- 相位以 `times[0]` 为历元；比较两次调用的相位前先对齐 `phase_epoch`。
- 窗口别名链接只在 **top 峰 vs 其它局部峰**之间、且两峰都在候选网格上
  时报告；别名频率本身未被候选网格覆盖时不会凭空生成。
