# 非均匀采样浮动均值谱估计 / Floating-mean periodogram

面向非均匀采样天文时间序列的可复用周期图模块：在每个候选频率上拟合
`y = c + a·cos(2πft) + b·sin(2πft)`（常数均值**浮动**，而非先扣除均值），
采用加权 Householder QR 最小二乘；功率定义为相对常量模型的加权残差平方和
（SSE）减少比例。另计算采样窗口的归一化模用于解释周期别名。

**联合拟合（本轮新增）**：`joint_periodogram_fit` 在一个**最多 12 点的有限
候选网格**上枚举 **1 个或 2 个不同频率**的全部组合（单频 m 个 + 频率对
m(m−1)/2 个，至多 66 个模型），每个组合在同一个加权 QR 最小二乘入口上
联合求解 `c + Σ(aⱼcos + bⱼsin)`，按**残差 SSE 升序、频率字典序升序**选出
最优子集；相近频率与精确别名导致的退化设计矩阵由数值秩判定处理。

**不使用 FFT、不把不等间隔观测插值/补零成均匀序列**；每个观测就是设计矩阵的
一行，重复时间、未排序时间均可直接处理。

- Python：**3.14.7**（库本体仅用标准库 `math`、`dataclasses`、`numbers`、
  `collections.abc`；测试额外使用 `itertools`/`os`/`sys`）
- 第三方依赖：**无**；安装 Python 后即可运行
- 完全离线：无网络、账号、密钥、数据库、中间件、云 API、Docker
- 示例数据由仓库内确定性 LCG 代码生成，无外部附件

## 接口

```python
from periodogram import periodogram, PeriodogramError, PeriodogramResult
# 联合 1-/2-频率枚举（本轮新增，见下文“联合拟合接口”）
from periodogram import joint_periodogram_fit, JointFrequencyFit

res = periodogram(times, values, weights, frequencies,
                  *, top_k=None, min_separation=0.0,
                  rank_tol=None, selection_budget=None)
```

| 参数 | 契约 |
|---|---|
| `times` | list/tuple 实数，有限（拒绝 NaN/±Inf），长度 3..200；可不排序、可重复 |
| `values` | 同长度有限实数 |
| `weights` | 同长度**严格正**有限权重；`None` 表示等权。全局权重缩放不改变结果 |
| `frequencies` | 1..300 个候选频率，**严格递增、严格为正**的有限实数（单位：周/时间单位） |
| `top_k` | 正整数且 ≤ 候选数；`None` 表示 `min(5, 候选数)`。**拒绝 bool** |
| `min_separation` | 非负有限频率排斥距离；已选峰与候选 `|Δf| < min_separation` 时排斥，`|Δf| == min_separation` **允许**（边界内闭） |
| `rank_tol` | 数值秩阈值，`|R_jj| > rank_tol·max|R_ii|` 判为非零；默认 `n·eps`；可覆盖范围 `(0,1)` |
| `selection_budget` | top-K 选择时检查的候选数上限；`None` = 全部候选（穷举扫描） |

返回不可变值对象 `PeriodogramResult`（逐频率数组 + 峰列表）：

- `frequencies, powers, amplitudes, phases, ranks, constants, sses`：每个候选
  频率的功率、幅度 `hypot(a,b)`、相位 `atan2(b,a)∈(−π,π]`、设计矩阵数值秩、
  拟合常数 c、加权 SSE。
- `sse0`、`weighted_mean`：常量模型 SSE 与加权均值。
- `window`（复数，τ=t−times[0] 参考系）与 `window_modulus`
  `= |Σ w_k exp(i2πft_k)| / Σw_k ∈ [0,1]`；模与时间原点无关，用于别名解释。
- `local_peaks`：严格局部功率极大（`P[i-1]<P[i]>P[i+1]`，端点永不算峰）。
- `top_peaks`：按功率降序（功率并列时频率升序）贪心选取，施加显式排斥距离；
  元素为 `FrequencyPeak(index, frequency, power, amplitude, phase, rank, sse,
  window_modulus)`。
- `selection_status`：
  - `"complete"`：扫描了全部候选；若 `top_k_found < top_k_requested`，
    这是在确定性贪心规则下**可证明无更多可选峰**的结果；
  - `"budget_exhausted"`：`selection_budget` 用尽、扫描提前终止；
    对未检查候选不作任何断言。**预算耗尽与证明无解严格分开**。

### 功率定义

`P(f) = (SSE0 − SSE(f)) / SSE0`，其中 `SSE0 = min_c Σw(y−c)²`（浮动均值常量
模型），`SSE(f)` 为三参数模型的最小二乘残差。普通条件下 `0 ≤ P ≤ 1`。

## 联合拟合接口（本轮新增）

```python
from periodogram import joint_periodogram_fit, JointFrequencyFit, JointFrequencyComponent

res = joint_periodogram_fit(times, values, weights, frequencies,
                            *, max_frequencies=2, rank_tol=None)
```

| 参数 | 契约 |
|---|---|
| `times` | 同 `periodogram`：有限实数，长度 3..200，可不排序、可重复 |
| `values` / `weights` | 同上；`weights=None` 等权，权重必须严格正，全局缩放不变 |
| `frequencies` | **1..12 个**严格递增、严格为正的有限候选频率（联合枚举专用上限） |
| `max_frequencies` | `1` 或 `2`（默认 `2`，**拒绝 bool/float/越界**）。为 2 时枚举全部 m 个单频与 m(m−1)/2 个频率对 |
| `rank_tol` | 同 `periodogram` 的数值秩阈值；默认 `n·eps`，可覆盖范围 `(0,1)` |

对每个非空子集（至多 66 个模型）求解

`y ~= c + Σⱼ (aⱼ·cos(2πfⱼt) + bⱼ·sin(2πfⱼt))`

线性系数走的是与 `periodogram` **同一个加权 Householder QR 入口**
（`_weighted_qr` / `_solve_triangular`，列数 3 或 5），是精确最小二乘解，
不做逐频率贪心、不坐标轮换。选择规则：

1. **加权残差 SSE 最小者胜**（与功率口径一致，常量模型同为浮动均值）；
2. SSE 位级并列时按**频率序列字典序升序**：单频 `(f_i,)` 先于一切频率对，
   对之间按 `(f_i, f_j)` 升序。枚举本身按此顺序进行，选择结果确定性可复现。

返回不可变值对象 `JointFrequencyFit`：

- `frequencies`：获胜频率元组，升序，长度 `order`（1 或 2）；
- `components`：逐频率的 `JointFrequencyComponent(frequency, amplitude,
  phase, cos_coefficient, sin_coefficient)`，相位 `atan2(b,a)∈(−π,π]`，
  系数为**原时间参考系**（内部 τ=t−times[0] 拟合后闭式旋转回去）；
- `constant`、`sse`、`sse0`、`power = (SSE0−SSE)/SSE0`、
  `weighted_mean`；
- `rank`：获胜模型设计矩阵的数值秩（精确别名对秩 ≤3，全部同刻观测秩 1）；
- `order`：获胜模型频率个数；`models_evaluated`：实际拟合的子集数
  （`m` 或 `m + m(m−1)/2`，网格不足时如实报告）；`rank_tol`。

### 联合拟合的退化与约定

- **精确别名**：采样时刻上两频率的 cos/sin 列位级相同（例如 24 个整点
  小时采样上 `f=3` 与 `f=3+24=27` 周/天）时，5 列设计矩阵秩为 3，频率对
  无法把 SSE 降到单频以下；按字典序并列规则由较小频率的**单频模型获胜**。
  这是真实秩亏，不会硬配出巨系数。
- **相近频率**：列强相关但非位级共线时 QR 仍给满秩解；能否区分取决于
  采样基线（拍频周期数），病态由条件数体现，模块不擅自合并频率。
- **观测不足**：`n < 1+2k` 时设计矩阵秩亏，秩判定把零方向系数置 0，
  仍从残差投影无歧义计算 SSE（与单频路径同一处理）。
- **位级常量数据**：精确返回 `SSE0=SSE=0、P=0、c=该常量、所有正弦系数 0`，
  字典序胜者为最小候选频率上的单频模型（避免 1e-30 级舍入残差任意选对）。

## 错误语义

- 所有数值输入拒绝 NaN / Infinity；整数参数（`top_k`、`selection_budget`、
  联合拟合的 `max_frequencies`）拒绝 `bool`（`True/False` 不会被当作 1/0），
  数组内的布尔元素同样拒绝。
- 非法输入抛 `PeriodogramError`（`ValueError` 子类），消息**点名参数与元素
  下标**（如 `values[7]: NaN is not allowed`、`frequencies[2]: candidates must
  be strictly increasing`、`max_frequencies: expected <= 2, got 3`），不静默
  纠正、不截断、不重排用户数据。
- 全部输入校验先于任何计算；两个入口都是纯函数（不写文件、不修改入参），
  不存在“部分完成”状态。
- 权重必须严格为正（零/负权重直接拒绝，而不是悄悄丢点）。

## 设计取舍

1. **加权 Householder QR（逐行构造 W^½A，3 列）**：不组正规方程，避免条件数
   平方化；n≤200、m≤300 下纯 Python 约 0.1 秒。这是本题核心算法，不调用任何
   第三方谱分析实现。
2. **时间原点重定中心**：内部以 `τ = t − times[0]` 拟合（大原点下保证三角
   参数有界），再用闭式旋转把 (a,b) 转回原时间参考系。功率、幅度、窗口模对
   原点平移在数学上严格不变；`window` 的复相位以 τ 参考系报告。
3. **SSE 直接按拟合模型残差计算**：当某列被数值秩判定跳过（秩亏）时，
   `Qᵀb` 的残差能量仍分布在被跳过列方向，直接取尾部会漏算；用投影拟合值
   计算对任意秩都无歧义。
4. **逐位常量值约定**：当所有 `values` 位级相等时，精确返回 `SSE0=0`、
   每频率 `P=0`、`a=b=0`、`c=该常量`，避免 0/0（这是文档化约定，不是用容差
   掩盖）。非位级常量的近常量数据照常按浮点计算。
5. **无插值/无网格/无 FFT**：候选频率由调用方显式给出；模块不假设均匀采样，
   也不做任何零填充。
6. **采样窗口**：报告 `|W|/Σw` 而非原始复和，天然归一到 `[0,1]` 且对权重
   全局缩放不变；均匀采样在 `f_s=1/Δt` 处模为 1，直接指示别名间隔。
7. **联合枚举（新）**：最多 2 个频率、最多 12 点网格意味着至多 66 个
   5 列模型，直接**穷举**而非启发式搜索，选择规则（SSE、频率字典序）可
   手算复核、不存在预算耗尽概念；线性系数复用同一 QR 入口，单频与双频
   口径严格一致。枚举只选频率子集，系数永远是该子集上的精确加权最小二乘。

## 已知限制（本题数学子集，不宣称行业标准兼容）

- 本轮范围：单变量时间、正弦+常量模型、标量权重。联合拟合**最多 2 个
  频率、候选网格最多 12 点**；不做三频及以上联合、连续频率精化（抛物线/
  亚格点/非线性优化）、别名模型的统计比较（如 BIC/FAP），也不做多谐波、
  误差棒传播、显著性统计检验、Lomb–Scargle 标准时移或任何行业标准合规声明。
- 峰位置与联合频率精度受候选网格步长限制，离线格点的信号会有频谱泄漏
  （幅度被低估），这是物理效应而非数值缺陷。
- 联合拟合只在给定网格上比较子集；两频率在采样基线上不可分辨时
  （设计矩阵病态）仍如实给满秩解，巨系数由条件数反映，模块不合并、不正则化。
- `phases` 在幅度接近 0 的分量上无物理意义（atan2(0,0)=0 的延续）。
- 观测时间跨度与周期相比极大时，二进制64浮点本身的时间量化会改变输入问题
   （例如原点平移 1e9 后相对时间误差可达 ~2·ulp(1e9)≈2.4e-7）；模块在
  “给定的浮点输入”上精确求解，但不消除输入表示误差。
- 纯解释器实现，规模上限即接口边界（单频 200×300；联合 200×12 网格、
  66 个模型）；不追求更大规模性能。

## 误差口径（README 明确承诺，不用宽容差掩盖边界）

二进制64 浮点，机器精度 `eps = 2.220446049250313e-16`。测试中的独立参考
（等间隔 DFT 闭式和、3×3/5×5 手工加权正规方程高斯消元、窗口直接几何求和、
小规模全子集枚举）**不调用被测核心**产生期望值；与被测代码的往返一致仅作
补充检查。

- **等间隔、信号落在 DFT 格点**：残差 SSE `< 1e-24`（相对功率 ≈ 1，
  达 `places=10`），幅度/相位/常数与解析 DFT 系数一致到 `places=10..12`。
- **非均匀时间 + 任意正权重**：QR 与独立正规方程参考逐 bin 比较
  `SSE/SSE0`，容差 `1e-18 + 1e-12·量值`（即 ~12 位有效数字）；
  幅度、相位、常数 `places=10`。在最病态 bin（拟合系数 ~50）正规方程自身
  条件数平方化、约有 1e-10 绝对误差，测试显式以
  `1e-11 + 1e-10·max(1,|x|)` 为界并要求 QR 不劣于参考——该容差是正规方程
  的已知误差界，非掩盖边界错误的“大网”。
- **联合拟合**：双 DFT 格点信号联合残差 `< 1e-26`，各分量系数与闭式 DFT
  系数一致到 `places=11`；非均匀加权双频与独立 5×5 正规方程参考及**全子集
  枚举参考**逐系数比较（SSE 容差 `1e-18 + 1e-11·量值`，系数 `places=10`，
  旋转回原时间系后比较）；权重全局缩放使 SSE 同比缩放、系数不变到
  `places=12`。
- **相近频率**：0.20 与 0.21（长基线可分辨）联合 SSE `< 1e-24`、秩 5、
  分量幅度/相位恢复到 `places=9`；短基线上 0.20 与 0.2005 列强相关但不满秩
  判定，无噪数据仍精确拟合（SSE `< 1e-20`，秩 5）——病态如实暴露而非掩盖。
- **精确别名退化**：整点采样上相差采样频率的两频位列位级相同，联合秩判为 3、
  对模型 SSE 不低于单频，字典序规则选单频，SSE 与独立 3×3 参考一致。
- **大原点平移（1e9）**：两帧各自对照独立参考（参考也在小角度 τ 帧求解）；
  跨帧相位旋转律 `φ₂−φ₁ = 2πfT` 以 `places=5` 检验——该比较中的旋转角
  高达 ~2.4e9 rad，`places=5` 对应约 2e-15 的**相对**精度。输入时间量化
  （≤2·ulp(T)，测试中先实测上界）作为真实输入扰动单独说明。
- **窗口模**：与直接复数几何求和一致到 `places=12..13`，且 ≤ 1+1e-15。
- **别名/秩亏/重复时间**：镜像别名两 bin 功率差 `places=12`；秩亏采样
  功率精确为 0、秩 ≤2（联合路径上全部同刻观测秩 1）；重复时间与独立正规
  方程一致到 `places=10`。

- 全部输入校验（NaN/Inf、bool、长度/上限、频率递增与为正、类型可定位错误）；
- **联合拟合（新）**：双 DFT 格点解析恢复、非均匀加权对独立 5×5 正规方程与
  全子集枚举参考、权重缩放不变、`max_frequencies=1` 路径、单点网格；
  精确别名对秩亏且字典序输给单频、位级常量字典序约定、结果确定性与分量升序；
  相近频率可分辨/短基线病态仍满秩、全部同刻观测秩 1、n=5 五参数精确插值、
  n=3（观测少于参数）秩亏不崩溃；
  `max_frequencies` 越界/bool/float、12 点上限、网格递增与为正、NaN/Inf/
  零权重、`rank_tol` 范围、入参不被修改（成功与失败调用）、结果不可变。

`python demo.py`（固定输入、确定性、约 0.1 秒，远低于 90 秒预算）：

1. **正常结果（单频扫描）**：25 晚 × 3 次的夜间观测节奏、注入 f=1.70/day
   信号；真实计算出 `1.70 / 0.70 / 2.70` 三峰歧义（P≈0.999 与 0.989），
   采样窗口在 1.00/day 处 |W|/Σw≈0.995 解释周日别名；主峰再用独立
   3×3 正规方程现场核对（差异 ~1e-16）。
2. **正常结果（联合枚举）**：48 个非均匀观测、12 点网格上枚举 78 个子集，
   真实恢复注入的 f=0.20/0.45 双信号（P≈0.9998）；胜对用独立 5×5 正规
   方程现场核对（差异 ~1e-17），并与最佳单频对比 SSE 下降幅度。
3. **边界（真实计算，非报错）**：整点采样上的精确别名对（秩 3、字典序选
   单频）与长基线上 0.20/0.21 相近频率（秩 5、双分量精确恢复）。
4. **实际触发的拒绝**：NaN 观测、`top_k=True`、`max_frequencies=3`、
   13 点联合网格都真正抛出 `PeriodogramError` 并打印可定位消息（不是预录文本）。
